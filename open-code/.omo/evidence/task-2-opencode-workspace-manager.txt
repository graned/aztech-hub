# Task 2 — Docker networking (opencode-workspace-manager)

Verified: 2026-08-19

## Files created
- Dockerfile (multi-stage: base/deps/dev/builder/runner, standalone output, git+openssh-client+curl in runtime)
- Dockerfile.opencode (ghcr.io/anomalyco/opencode:latest + git/openssh-client/curl via apk; Alpine 3.24.1, runs as root, entrypoint `opencode`)

## Acceptance criteria
1. `docker compose -f docker-compose.local.yml --env-file .env.example config` -> exit 0
2. `docker compose -f docker-compose.prod.yml --env-file .env.example config` -> exit 0
3. Config output has ONLY Caddy host ports:
   - local: single published port `80` (127.0.0.1:80->80)
   - prod: `80`, `443`, `443` (udp)
   - app/mongodb/opencode expose NO host ports
4. Shared workspace volume: `workspace-data` mounted at `/workspaces` on BOTH app and opencode
5. Dedicated network: all four services on `aztech-opencode-workspace-manager-local` bridge
