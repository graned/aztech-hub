## SDK contract notes (verified against @opencode-ai/sdk 1.18.18 + pinned server)
- SSE subscribe returns `{ stream: AsyncGenerator }`; SDK stream reconnects forever unless the provided AbortSignal aborts -> gateway threads `signal` through and tests abort before breaking.
- `Part` tool state is `toolState.status`; step-start carries no `reason`; retry error text is `part.error.data.message`.
- Global event envelope is `{ directory, payload: Event }`; session events carry `properties.info.id`.

## Build / resolution fix
- tsx runtime import of `@opencode-ai/sdk` from nested .ts throws `ERR_PACKAGE_PATH_NOT_EXPORTED` (SDK exports map has `import`/`types` only; tsx CJS fallback does not apply `import` condition). Fixed by a dedicated `tsconfig.test.json` `paths` alias to `./node_modules/@opencode-ai/sdk/dist/index.js` used only by tsx at runtime; main `tsconfig.json` is left clean so `tsc`/Next resolve real declarations.
